AstroAtlasI
AstroAtlasI — MVP prototype of the release-plan §11 loop: chart calculation, the 21-day cycle (solo Weeks 1–2, solo Week 3, Week 3 with a consenting second person), a small Galaxy view, and real deletion. Start on the Chart tab.

Chart engine runs on a free, MIT-licensed astronomy library as a stand-in for the paid Swiss Ephemeris SDK (see Construction Site). Data is stored only in this browser — no account, no server, per release plan §7's "lighter-weight" prototype scope.
